Add the teamwork unit

This is the complete updated English This / IH Challenges app.

  1. Open the GitHub repository already connected to your Netlify app.
  2. Upload the contents of this english-this folder, keeping the public and netlify folders and replacing the matching files.
  3. Commit your changes and wait for Netlify to show Published.
  4. Reload your app. Choose Continue → Self-study.

Keep your existing Netlify API key. No new setting is needed.

Try it

Open Working in a team. Try an incorrect answer, retry, then try a writing task. Recording needs microphone permission. AI feedback and transcription need an internet connection and your existing AI setup.

The unit is B1. Completion shows practice, not a test result. No listening activity is included.
